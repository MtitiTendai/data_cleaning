<h1 align="center">Life Expectancy Data Preprocessing and Cleaning</h1>


## The following are very crucial steps for every data scientist/ machine learning engineer to do before developing a machine learning model.


### Step 1 - Import necessary libraries 

Involves importing the Python libraries required for data analysis, preprocessing, visualisation, and other operations performed during the project.

Step 2 - Load and read the dataset

Involves loading of data into the working environment and viewing it. Various data formats like CSV, XLSX, JSON, and XLS can be imported into Jupyter Notebook.

Step 3 - Sanity check of data

Involves checking the structure, data types, dimensions, and general quality of the dataset to identify possible errors or inconsistencies.

Step 4 - Exploratory Data Analysis (EDA)

Involves exploring and understanding the dataset using statistical summaries and visualisations to identify patterns, relationships, and trends in the data.

Step 5 - Missing value handling

Involves identifying missing values in the dataset and applying appropriate methods to handle them, such as removing or replacing the missing values.

Step 6 - Outlier handling

Involves identifying unusual or extreme values in the dataset and applying suitable techniques to manage or remove them where necessary.

Step 7 - Duplicates and garbage value treatment

Involves identifying and removing duplicate records, correcting invalid entries, and cleaning unwanted or inconsistent values from the dataset.

Step 8 - Normalisation

Involves transforming numerical data to a common scale so that variables with different ranges can be used effectively during data analysis and machine learning.

Step 9 - Encoding of data

Involves converting categorical or text-based data into numerical values so that it can be processed by machine learning algorithms.
